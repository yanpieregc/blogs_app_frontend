# App de Blogs(Front-end)
Interfaz web que permite administrar blogs.
Consume la API REST desarrollada en el repositorio del back-end

## Back-end
https://github.com/yanpieregc/blogs_app_backend

## Tecnologías
- JavaScript
- React

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Crear blogs
- Votar blogs
- Eliminar blogs

## Instalación
- pnpm install
- pnpm run dev
